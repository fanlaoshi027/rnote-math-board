# Rnote Math Board

基于 Rnote 改造的数学教师专用手写白板。

## 项目目标

- 保留 Rnote 优秀的手写、压感与画布能力
- 采用简洁、现代、面向数学讲课的 UI
- 参考专业 PDF/白板软件的工具栏交互逻辑
- 后续加入收藏笔、数学绘图工具、题目/PDF 讲解等功能

## 开发原则

第一阶段优先保证书写手感，不贸然修改 Rnote 的核心手写引擎。

- [ ] 导入并固定 Rnote 上游版本
